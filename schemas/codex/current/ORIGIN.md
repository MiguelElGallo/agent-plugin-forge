# Codex compatibility contract

This repository-maintained schema captures the generated, skills-only subset accepted by the current Codex local plugin validator on 2026-08-21. It is a compatibility contract, not an OpenAI-published schema and not part of Agent Plugins 1.0.

The behavioral reference is the validator distributed with Codex's `plugin-creator` system skill. The forge also runs Pydantic semantic checks and validates each fully staged wrapper, including its skill tree.
